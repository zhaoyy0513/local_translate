# 🎙️ 实时语音识别与翻译系统

一个基于 Whisper + Google Translate 的实时语音识别与翻译工具。可以捕获系统音频（如 YouTube、Teams 会议、音乐播放器等），将英文语音实时转录为文字，并翻译为中文。

## 核心技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| **后端框架** | FastAPI | 高性能异步 Web 框架 |

| **数据存储** | Redis Stream | 高性能时序数据存储 |
| **实时通信** | WebSocket | 双向实时通信 |
| **前端** | Alpine.js + Tailwind CSS | 轻量级响应式 UI |

## 工作流程

### 1. 音频捕获流程

```
系统音频 (YouTube/Teams/Music)
         │
         ▼
┌─────────────────────────────────────┐
│  Windows 立体声混音 (Stereo Mix)     │
│  或 WASAPI Loopback 设备            │
└─────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  PyAudio 音频流捕获                  │
│  - 格式: 16-bit PCM                 │
│  - 声道: 立体声 → 单声道             │
│  - 采样率: 48000 Hz → 16000 Hz      │
│  - 块大小: 每 6 秒处理一次           │
└─────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  静音检测 (VAD)                      │
│  - 音量阈值: 0.005                   │
│  - 低于阈值则跳过                    │
└─────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────┐
│  Whisper 语音识别                    │
│  - 语言: 英文 (en)                   │
│  - VAD 过滤: 启用                    │
│  - Beam Size: 5                     │
└─────────────────────────────────────┘
         │
         ├──────────────────────────────┐
         ▼                              ▼
┌─────────────────┐          ┌─────────────────┐
│  保存英文到 Redis │          │  加入翻译队列    │
│  推送到前端       │          │  (异步处理)      │
└─────────────────┘          └─────────────────┘
                                       │
                                       ▼
                             ┌─────────────────┐
                             │  Google 翻译     │
                             │  保存中文到 Redis │
                             │  推送到前端       │
                             └─────────────────┘
```

### 2. 翻译服务原理 (Google Translate)

本项目使用 `deep-translator` 库调用 Google 翻译服务：

```python
from deep_translator import GoogleTranslator

translator = GoogleTranslator(source='en', target='zh-CN')
result = translator.translate("Hello world")  # → "你好世界"
```

**关键特性：**

| 特性 | 说明 |
|------|------|
| **是否免费** | ✅ 完全免费，无需 API Key |
| **调用方式** | 通过 Google Translate 网页接口 |
| **请求限制** | 无官方限制，但高频请求可能被临时封禁 |
| **翻译质量** | 与 Google 翻译网页版相同 |
| **支持语言** | 100+ 种语言互译 |

**工作原理：**
```
┌─────────────────────────────────────────────────────────────┐
│                    deep-translator 库                        │
│                                                              │
│  1. 构造 HTTP 请求到 translate.google.com                    │
│  2. 模拟浏览器行为发送翻译请求                                │
│  3. 解析返回的 HTML/JSON 获取翻译结果                         │
│  4. 返回翻译文本                                             │
│                                                              │
│  优点: 免费、无需注册、翻译质量好                             │
│  缺点: 依赖网络、可能被限流                                   │
└─────────────────────────────────────────────────────────────┘
```

## 安装与配置

### 前置要求

- Python 3.10+
- Redis Server
- Windows 系统 (需要启用立体声混音)
- 支持 CUDA 的显卡 (可选，用于 GPU 加速)

### 1. 克隆项目

```bash
git clone <repository_url>
cd local_translate
```

### 2. 创建虚拟环境

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

**依赖说明：**

| 包名 | 版本 | 用途 |
|------|------|------|
| fastapi | 0.115.0 | Web 框架 |
| uvicorn | 0.32.0 | ASGI 服务器 |
| redis | 5.2.0 | Redis 客户端 |
| faster-whisper | 1.0.3 | 语音识别 |
| deep-translator | 1.11.4 | Google 翻译 |
| pyaudio | 0.2.14 | 音频捕获 |
| python-dotenv | 1.0.1 | 环境变量 |
| pydantic | 2.9.2 | 数据校验 |
| websockets | 13.1 | WebSocket |

### 4. Windows 启用立体声混音

这是**最关键的一步**，用于捕获系统音频：

1. 右键点击任务栏音量图标 → **声音设置**
2. 找到 **声音控制面板** (或直接搜索 "声音")
3. 切换到 **录制** 标签页
4. 右键空白处 → 勾选 **显示禁用的设备**
5. 找到 **立体声混音** (Stereo Mix)
6. 右键 → **启用**
7. 右键 → **设为默认设备** (可选)

> ⚠️ 如果找不到立体声混音，可能需要更新声卡驱动或使用第三方虚拟音频设备。

### 5. 查找音频设备索引

运行测试脚本查看所有音频设备：

```bash
python test_audio_devices.py
```

输出示例：
```
[0] Microsoft Sound Mapper - Input (MME)
[1] Microphone (Realtek Audio) (MME)
...
[24] 立体声混音 (Realtek HD Audio) (WASAPI)  ← 使用这个索引
...
```

找到 **立体声混音** 或 **Stereo Mix** 对应的索引号。

### 6. 配置环境变量

复制示例配置文件：

```bash
cp .env.example .env
```

编辑 `.env` 文件（详见下一节）。

### 7. 启动 Redis

```bash
# Windows (使用 Docker)
docker run -d -p 6379:6379 redis

# 或本地安装的 Redis
redis-server
```

### 8. 启动后端服务

```bash
python -m uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

### 9. 打开前端页面

用浏览器打开 `frontend/index.html` 文件，或通过 HTTP 服务器访问。

## 配置详解

### .env 配置文件

```bash
# ==================== Redis 配置 ====================
REDIS_HOST=localhost          # Redis 服务器地址
REDIS_PORT=6379               # Redis 端口
REDIS_DB=0                    # Redis 数据库编号
REDIS_PASSWORD=               # Redis 密码 (无密码留空)

# ==================== Whisper 模型配置 ====================
WHISPER_MODEL=medium          # 模型大小 (见下表)
WHISPER_DEVICE=cpu            # 运行设备: cpu 或 cuda
WHISPER_COMPUTE_TYPE=int8     # 计算精度: int8/float16/float32

# ==================== 音频配置 ====================
SAMPLE_RATE=48000             # 音频采样率 (匹配设备)
CHUNK_DURATION=6              # 每次处理的音频时长 (秒)
AUDIO_DEVICE_INDEX=24         # 音频设备索引 (立体声混音)

# ==================== 翻译配置 ====================
ENABLE_TRANSLATION=true       # 是否启用翻译
SOURCE_LANG=en                # 源语言
TARGET_LANG=zh-CN             # 目标语言
```

### Whisper 模型选择

| 模型 | 大小 | 显存需求 | 相对速度 | 准确度 | 推荐场景 |
|------|------|---------|---------|--------|---------|
| `tiny` | 39M | ~1GB | 最快 | 较低 | 快速测试 |
| `base` | 74M | ~1GB | 很快 | 一般 | 简单对话 |
| `small` | 244M | ~2GB | 快 | 较好 | 日常使用 |
| `medium` | 769M | ~5GB | 中等 | 很好 | **推荐** |
| `large-v2` | 1550M | ~10GB | 慢 | 最佳 | 高精度需求 |

**推荐配置：**

```bash
# CPU 用户 (无显卡)
WHISPER_MODEL=medium
WHISPER_DEVICE=cpu
WHISPER_COMPUTE_TYPE=int8

# GPU 用户 (有 NVIDIA 显卡)
WHISPER_MODEL=medium
WHISPER_DEVICE=cuda
WHISPER_COMPUTE_TYPE=float16
```

### 音频采样率说明

不同音频设备有不同的采样率，常见值：

| 采样率 | 说明 |
|--------|------|
| 16000 Hz | Whisper 原生支持 |
| 44100 Hz | CD 音质 |
| 48000 Hz | 专业音频/视频标准 |

系统会自动将音频重采样到 16000 Hz 供 Whisper 使用。

**如何确定设备采样率：**

```bash
python test_audio_devices.py
```

查看设备的 `defaultSampleRate` 字段。

## API 接口

### 翻译控制

#### POST /api/translation/start
开始语音识别

**响应：**
```json
{
  "success": true,
  "message": "翻译已启动",
  "data": {
    "session_key": "2026_02_11_16_30_1707661800000"
  }
}
```

#### POST /api/translation/stop
停止语音识别

#### GET /api/translation/status
获取当前状态

**响应：**
```json
{
  "success": true,
  "data": {
    "is_running": true,
    "current_session": "2026_02_11_16_30_1707661800000"
  }
}
```

### 历史记录

#### GET /api/sessions
获取所有会话列表

**响应：**
```json
{
  "success": true,
  "data": {
    "sessions": [
      "2026_02_11_16_30_1707661800000",
      "2026_02_10_14_20_1707575400000"
    ]
  }
}
```

#### GET /api/records/{session_key}/{lang}
查询指定会话的记录

**参数：**
- `session_key`: 会话标识
- `lang`: 语言 (`en` 或 `zh`)
- `count`: 返回数量 (默认 50)

**响应：**
```json
{
  "success": true,
  "total": 100,
  "records": [
    {
      "timestamp": 1707661800000,
      "text": "Hello world",
      "session_key": "2026_02_11_16_30_1707661800000",
      "lang": "en"
    }
  ]
}
```

### 导出功能

#### GET /api/export/{session_key}
导出会话记录

**参数：**
- `format`: 导出格式 (`txt` 或 `json`)
- `lang`: 语言选择 (`en` / `zh` / `both`)

**示例：**
```
GET /api/export/2026_02_11_16_30_1707661800000?format=txt&lang=both
```

### WebSocket

#### WS /ws
实时消息推送

**消息格式：**
```json
{
  "type": "recognition",
  "lang": "en",
  "text": "Hello world",
  "timestamp": 1707661800000
}
```

## 常见问题

### Q1: 识别不到音频/没有输出

**原因：** 音频设备选择错误

**解决：**
1. 运行 `python test_audio_devices.py` 查看设备列表
2. 找到 "立体声混音" 或 "Stereo Mix" 的索引
3. 在 `.env` 中设置 `AUDIO_DEVICE_INDEX=<索引号>`
4. 运行 `python test_audio_capture.py` 验证能否捕获到音量

### Q2: 识别结果非常不准确

**原因：** 模型太小或采样率不匹配

**解决：**
1. 升级模型：`WHISPER_MODEL=medium`
2. 增加处理时长：`CHUNK_DURATION=6`
3. 确认采样率与设备匹配

### Q3: 翻译速度很慢

**原因：** 翻译是异步处理的，与识别不在同一线程

**这是正常现象：**
- 识别和翻译是解耦的，翻译不会阻塞识别
- 翻译结果会稍后推送到前端
- 导出时可以选择 "English Only" 避免翻译延迟问题

### Q4: WebSocket 连接断开

**原因：** 网络不稳定或服务器重启

**解决：** 前端已实现自动重连 (2秒后重试)

### Q5: Redis 连接失败

**解决：**
1. 确认 Redis 服务已启动
2. 检查 `.env` 中的 Redis 配置
3. 如有密码，设置 `REDIS_PASSWORD`

### Q6: GPU 加速不生效

**解决：**
1. 安装 CUDA 版本的 PyTorch
2. 设置 `WHISPER_DEVICE=cuda`
3. 设置 `WHISPER_COMPUTE_TYPE=float16`
